# The Last Sentence

霧の多い、北の港町。

坂の上の家から、石畳の市場、海へ続く桟橋まで。歩いて回れる小さな町で、言葉がまだうまく届かない朝が始まります。

## この作品について

あなたは港町で目を覚まします。人の声は聞こえるのに、書かれた文字や、交わされる言葉の一部が、見慣れない記号のように感じられます。

町の人たちは、それぞれの暮らしの途中にいます。急かさず、問い詰めず、話を聞いたり、場所を訪ねたりしているうちに、少しずつ言葉がつながっていきます。

これは、記号を読み解いていく物語です。答えを急がなくても大丈夫です。町を歩き、人の言葉に耳を澄ませてみてください。

## 遊び方

1. [last-sentence.html](./last-sentence.html) を開きます（初回は読み込みに少し時間がかかることがあります）。
2. 画面をクリック／タップして開始します。
3. 選択肢や場所は、マウス（またはタッチ）で選びます。
4. 台詞の進行は、クリック／タップ、または `Space` / `Enter` でも進められます。
5. 会話に出てきた記号を選ぶと、自分の辞書に読みを残せます。覚えた読みは、あとから見返せます。

町には、家や駅、市場、医院など、いくつか行き来できる場所があります。地図から行き先を選び、その日にできることのうち、気になるほうへ進んでください。

## セーブについて

進行状況は、お使いのブラウザに自動で保存されます。同じブラウザで同じページを開き直せば、続きから遊べます。

サイトのデータを消したり、別のブラウザや端末で開いたりすると、続きは残りません。

## 動作環境

- 対応ブラウザの最新版（デスクトップ／スマートフォン）
- 初回起動時は、実行環境の取得のためにインターネット接続が必要です
